# Сайт детского центра «Мы друзья» — фронтенд

Vue 3 + Vite + TypeScript. Вёрстка на чистом CSS с дизайн-токенами, mobile-first.

## Запуск

```bash
cd frontend
npm install      # один раз — поставить зависимости
npm run dev      # запустить дев-сервер (http://localhost:5173)
```

Другие команды:

```bash
npm run build        # production-сборка в папку dist/
npm run preview      # посмотреть собранную версию
npm run type-check   # проверить типы TypeScript
```

## Как менять типовые вещи

**Поменять цвет/шрифт/отступ везде сразу** — `src/assets/styles/tokens.css`.
Все стили ссылаются на переменные оттуда, например `var(--color-primary)`.

**Поменять тексты, цены, контакты** — файлы в `src/data/`.
Правишь данные — страницы обновляются сами.

**Добавить страницу**:

1. Создай файл во `views/`, например `MyPage.vue`.
2. Добавь маршрут в `src/router/index.ts`.
3. При необходимости добавь ссылку в `src/data/navigation.ts`.

## Про адаптивность (mobile-first)

Вёрстка сначала рассчитана на телефон, а на широких экранах «раскрывается».
Ключевые приёмы в коде:

- **`.grid`** (в `utilities.css`) — карточки сами переносятся на новую строку
  через `repeat(auto-fit, minmax(...))`, почти без медиа-запросов.
- **`clamp()`** в токенах — размеры шрифтов и отступов плавно растут с шириной экрана.
- **Медиа-запросы** `@media (max-width: ...)` — точечно меняют раскладку
  (например, шапка прячет меню и показывает бургер на ширине ≤ 960px).

## Подключение бэкенда (потом)

Сейчас данные лежат в `src/data/*.ts`. Когда появится API, замени импорт
статических данных на загрузку через `fetch`. Типы из `data/types.ts`
переиспользуются — договорись, чтобы бэкенд отдавал JSON той же структуры.

Пример места для запроса — форма в `views/ContactsView.vue` (функция `submit`).
