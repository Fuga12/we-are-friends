# Контракты API — сайт «Мы Друзья»

Документ описывает ручки бэкенда, которыми нужно заменить статические заглушки
во фронтенде. Сейчас все данные лежат в `frontend/src/data/*.ts` и типизированы
в [`frontend/src/data/types.ts`](../frontend/src/data/types.ts). Ответы API
**должны совпадать с этими типами** — тогда фронтенд заработает без переделок,
достаточно будет заменить импорт из `@/data/...` на запрос к API.

С бэкенда задаются: **новости, занятия (курсы), услуги, педагоги, документы,
галерея**. Дополнительно (тоже сейчас в заглушках): отзывы и общая информация
о центре — описаны в конце как опциональные.

---

## Общие соглашения

- **Базовый URL:** `/api` (например `https://мыдрузья.рф/api`).
- **Формат:** JSON, кодировка UTF-8, `Content-Type: application/json; charset=utf-8`.
- **Только чтение:** публичному сайту нужны только `GET`. Создание/редактирование —
  задача админки, здесь не описывается.
- **Идентификаторы (`id`):** строки-слаги (`"stolyarka"`, `"second-location"`).
  Именно `id` используется в URL страниц: `/classes/:id`, `/news/:id`.
- **Даты:** формат ISO `YYYY-MM-DD` (например `"2025-07-21"`).
- **Медиа (`photo`, `image`, `url`):** абсолютный путь или полный URL до файла
  (например `/media/photos/090.jpg` или `https://cdn.../090.jpg`). Поле `photo`
  необязательное — если его нет, фронт показывает заглушку с эмодзи.
- **Цвета (`color`):** одно из `"teal" | "orange" | "amber" | "red"` — это тема
  оформления карточки на сайте, не произвольный цвет.

### Формат списков

Списки можно отдавать двумя способами. Фронт проще всего поддержит **плоский
массив**:

```json
[ { "id": "..." }, { "id": "..." } ]
```

Если в будущем понадобится пагинация — обернуть в объект:

```json
{ "items": [ ... ], "total": 42, "page": 1, "pageSize": 20 }
```

Рекомендация: пока отдаём плоские массивы (данных немного).

### Ошибки

```json
{ "error": { "code": "not_found", "message": "Занятие не найдено" } }
```

Коды статусов: `200` — успех, `404` — сущность не найдена, `500` — ошибка сервера.

## 1. Новости

Используется на страницах: главная (последние новости),
[`/news`](../frontend/src/views/NewsView.vue),
[`/news/:id`](../frontend/src/views/NewsDetailView.vue).

### `GET /api/news`

Список новостей. Сортировка — по `date`, от новых к старым.

**Поля элемента** (`NewsPost`):

| Поле       | Тип        | Обяз. | Описание |
|------------|------------|:---:|----------|
| `id`       | string     | ✔ | Слаг для URL `/news/:id` |
| `title`    | string     | ✔ | Заголовок |
| `date`     | string     | ✔ | Дата публикации, `YYYY-MM-DD` |
| `category` | string     | ✔ | Рубрика: «Важное», «Лето», «Мастер-классы» и т.п. |
| `excerpt`  | string     | ✔ | Краткий анонс для карточки |
| `emoji`    | string     | ✔ | Эмодзи-заглушка, если нет фото |
| `photo`    | string     | — | Обложка новости |
| `content`  | string[]   | — | Полный текст, массив абзацев (для страницы новости) |

> В списке `content` можно не присылать (для экономии), но тогда он обязателен
> в ответе `GET /api/news/:id`.

### `GET /api/news/:id`

Одна новость целиком (обязательно с `content`). `404`, если новости нет.

**Пример:**

```json
{
  "id": "second-location",
  "title": "Мы открываем вторую точку!",
  "date": "2025-07-21",
  "category": "Важное",
  "excerpt": "С нового учебного года занятия проходят в двух помещениях…",
  "emoji": "🎉",
  "photo": "/media/photos/090.jpg",
  "content": [
    "У нас большая новость: с нового учебного года центр работает на двух площадках!",
    "Основная площадка остаётся на пр. А. Невского, 60, а новый филиал…"
  ]
}
```

## 2. Занятия (курсы)

Используется на страницах: главная (направления),
[`/classes`](../frontend/src/views/ClassesView.vue),
[`/classes/:id`](../frontend/src/views/ClassDetailView.vue).

### `GET /api/classes`

Список занятий (порядок = порядок вывода на сайте).

**Поля элемента** (`ClassItem`):

| Поле              | Тип      | Обяз. | Описание |
|-------------------|----------|:---:|----------|
| `id`              | string   | ✔ | Слаг для URL `/classes/:id` |
| `title`           | string   | ✔ | Название («Столярка») |
| `ageRange`        | string   | ✔ | Возраст («8–13+ лет») |
| `description`     | string   | ✔ | Короткое описание для карточки |
| `schedule`        | string   | ✔ | Расписание («Чт 17:00, Пт 16:00») |
| `price`           | string   | ✔ | Цена строкой («3600 ₽ / 4 занятия · разовое 1200 ₽») |
| `emoji`           | string   | ✔ | Эмодзи-заглушка |
| `color`           | enum     | ✔ | `teal \| orange \| amber \| red` — тема карточки |
| `photo`           | string   | — | Фото занятия |
| `fullDescription` | string[] | — | Развёрнутое описание (абзацы) для страницы занятия |
| `highlights`      | string[] | — | «Что получит ребёнок» — список тезисов |

> `price` и `schedule` — намеренно **строки**, а не числа: расписание и тарифы
> в центре нерегулярные («2000 ₽ / 4 занятия · разовое 900 ₽»). Не разбивать на
> числа без необходимости.

### `GET /api/classes/:id`

Одно занятие целиком (с `fullDescription` и `highlights`). `404`, если нет.

**Пример:**

```json
{
  "id": "stolyarka",
  "title": "Столярка",
  "ageRange": "8–13+ лет",
  "description": "Настоящая столярная мастерская: ручной и электроинструмент…",
  "schedule": "Чт 17:00, Пт 16:00, Сб, Вс",
  "price": "3600 ₽ / 4 занятия · разовое 1200 ₽",
  "emoji": "🪚",
  "color": "orange",
  "photo": "/media/photos/090.jpg",
  "fullDescription": [
    "Столярная мастерская — одно из любимых направлений центра…",
    "Каждый ребёнок уносит домой готовое изделие…"
  ],
  "highlights": [
    "Настоящие инструменты и станки",
    "Изделия из дерева своими руками"
  ]
}
```

## 3. Услуги

Услуги — это крупные предложения с отдельными страницами: **День рождения**,
**Мастер-классы**, **Летние программы**. У них две части:

1. **Карточка услуги** — показывается на главной и в выпадающем меню
   (тип `SpecialOffer`).
2. **Контент страницы услуги** — уникальный для каждой услуги (пакеты, шаги,
   смены, распорядок). Сейчас он захардкожен прямо в компонентах
   [`BirthdayView`](../frontend/src/views/special/BirthdayView.vue),
   [`MasterclassesView`](../frontend/src/views/special/MasterclassesView.vue),
   [`SummerView`](../frontend/src/views/special/SummerView.vue).

### `GET /api/services`

Список карточек услуг.

**Поля элемента** (`SpecialOffer`):

| Поле          | Тип      | Обяз. | Описание |
|---------------|----------|:---:|----------|
| `id`          | string   | ✔ | Слаг (`birthday`, `masterclasses`, `summer`) |
| `title`       | string   | ✔ | Название |
| `tagline`     | string   | ✔ | Короткий подзаголовок |
| `description` | string   | ✔ | Описание для карточки |
| `features`    | string[] | ✔ | Список ключевых пунктов |
| `price`       | string   | ✔ | Цена строкой («8 000 ₽», «по запросу») |
| `emoji`       | string   | ✔ | Эмодзи |
| `to`          | string   | ✔ | Внутренний путь на страницу услуги (`/special/birthday`) |
| `color`       | enum     | ✔ | `teal \| orange \| amber \| red` |

**Пример элемента:**

```json
{
  "id": "birthday",
  "title": "День рождения в центре",
  "tagline": "Праздник с мастер-классом",
  "description": "Отмечаем день рождения с пользой: аренда, чаепитие и мастер-класс…",
  "features": [
    "Кулинарный или столярный мастер-класс",
    "Помещение и чаепитие",
    "До 10 детей"
  ],
  "price": "8 000 ₽",
  "emoji": "🎉",
  "to": "/special/birthday",
  "color": "orange"
}
```

### `GET /api/services/:id`

Полный контент страницы услуги. Ответ = поля карточки (см. выше) **плюс** поле
`detail` с блоками, специфичными для конкретной услуги.

У трёх услуг структура `detail` разная — ниже описан каждый случай. Все блоки
внутри `detail` необязательные: чего нет, то фронт просто не рисует.

#### `birthday` — День рождения

```json
{
  "id": "birthday",
  "title": "День рождения ребёнка",
  "...": "остальные поля карточки",
  "detail": {
    "hero": {
      "subtitle": "Организуем праздник «под ключ»…",
      "emoji": "🎉",
      "tone": "orange"
    },
    "packages": [
      {
        "emoji": "🧁",
        "title": "Кулинарный праздник",
        "price": "8 000 ₽",
        "text": "Аренда, чаепитие и кулинарный мастер-класс…"
      }
    ],
    "steps": [
      { "title": "Выбираете дату", "text": "Звоните нам, подбираем время…" }
    ]
  }
}
```

- `packages[]` — `{ emoji, title, price, text }`
- `steps[]` — `{ title, text }` (блок «Как всё проходит»)

#### `masterclasses` — Мастер-классы

```json
{
  "id": "masterclasses",
  "detail": {
    "hero": { "subtitle": "…", "emoji": "🎭" },
    "intro": "Каждый мастер-класс — это готовый маленький праздник творчества…",
    "formats": [
      { "emoji": "🏠", "title": "У нас в центре", "text": "Приходите группой…" }
    ],
    "topics": [
      { "emoji": "🎨", "title": "Роспись", "text": "Раскрашиваем гипсовые фигурки…" }
    ]
  }
}
```

- `intro` — вводный абзац
- `formats[]` — `{ emoji, title, text }` (у нас / выездной формат)
- `topics[]` — `{ emoji, title, text }` (что можно попробовать)

#### `summer` — Летние программы

```json
{
  "id": "summer",
  "detail": {
    "hero": { "subtitle": "Городской лагерь дневного пребывания…", "emoji": "☀️", "tone": "amber" },
    "shifts": [
      {
        "emoji": "🪄",
        "title": "Школа магии: Тайная миссия",
        "dates": "13–24 июля",
        "photo": "/media/photos/177.jpg",
        "text": "Ребята становятся учениками школы волшебства…",
        "activities": ["Квест и магические испытания", "Опыты и эксперименты"]
      }
    ],
    "schedule": [
      { "time": "9:00", "text": "Сбор, зарядка и планы на день" }
    ]
  }
}
```

- `shifts[]` — `{ emoji, title, dates, photo?, text, activities[] }` (смены)
- `schedule[]` — `{ time, text }` (примерный распорядок дня)

> Если переносить контент страниц услуг на бэкенд пока не нужно, можно на первом
> этапе отдавать только `GET /api/services` (карточки), а содержимое страниц
> оставить в компонентах. Тогда `detail` добавить позже.

## 4. Педагоги (сотрудники)

Используется на странице [`/about/staff`](../frontend/src/views/about/StaffView.vue).

### `GET /api/staff`

Список сотрудников (порядок = порядок вывода).

**Поля элемента** (`StaffMember`):

| Поле       | Тип    | Обяз. | Описание |
|------------|--------|:---:|----------|
| `id`       | string | ✔ | Идентификатор |
| `name`     | string | ✔ | ФИО |
| `role`     | string | ✔ | Должность |
| `bio`      | string | ✔ | Короткое описание |
| `initials` | string | ✔ | Инициалы для аватара-заглушки, если нет фото |
| `color`    | enum   | ✔ | `teal \| orange \| amber \| red` |

> Сейчас у сотрудника нет поля фото — только `initials`. Когда появятся
> фотографии, стоит добавить необязательное `photo?: string` (по аналогии с
> занятиями) и обновить тип на фронте.

**Пример элемента:**

```json
{
  "id": "1",
  "name": "Анна Ивановна Петрова",
  "role": "Руководитель центра",
  "bio": "Педагог с 15-летним стажем…",
  "initials": "АП",
  "color": "teal"
}
```

## 5. Документы

Используется на странице [`/about/documents`](../frontend/src/views/about/DocumentsView.vue).

### `GET /api/documents`

Список документов (лицензии, устав, договоры и т.п.).

**Поля элемента** (`DocumentItem`):

| Поле          | Тип    | Обяз. | Описание |
|---------------|--------|:---:|----------|
| `id`          | string | ✔ | Идентификатор |
| `title`       | string | ✔ | Название документа |
| `description` | string | ✔ | Краткое описание |
| `fileType`    | string | ✔ | Тип файла («PDF») |
| `fileSize`    | string | ✔ | Размер строкой («1,4 МБ») |
| `url`         | string | ✔ | Ссылка на файл для скачивания |

> `fileType` и `fileSize` показываются пользователю на кнопке скачивания.
> Их можно вычислять на бэкенде из самого файла, но в ответе они должны быть
> строками в готовом виде.

**Пример элемента:**

```json
{
  "id": "1",
  "title": "Лицензия на образовательную деятельность",
  "description": "Действующая лицензия с приложениями.",
  "fileType": "PDF",
  "fileSize": "1,4 МБ",
  "url": "/media/docs/license.pdf"
}
```

|---------|--------|:---:|----------|

## Опционально (тоже сейчас в заглушках)

Не входит в основной запрос, но данные так же захардкожены и в будущем логично
вынести на бэкенд.

### `GET /api/reviews` — отзывы

Используется на главной и на [`/about/reviews`](../frontend/src/views/about/ReviewsView.vue).
Тип `Review`: `{ id, author, role, text, rating }`, где `rating` — число 1–5.

### `GET /api/site` — общая информация о центре

Контакты, адреса, соцсети, координаты для карты. Используется в шапке, подвале и
на [`/contacts`](../frontend/src/views/ContactsView.vue). Структура — как объект
`site` в [`frontend/src/data/site.ts`](../frontend/src/data/site.ts):
`name, tagline, description, phone, phoneHref, phone2, phone2Href, email,
address, address2, address2Note, workingHours, vk, vkMarket, geo { lat, lng }`.

> Меню (`navigation.ts`) остаётся на фронте — это структура сайта, а не контент,
> и завязана на маршруты роутера.

| GET   | `/api/gallery`        | Галерея                          |

| GET   | `/api/site`           | Инфо о центре (опционально)      |
