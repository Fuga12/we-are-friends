# Бэкенд «Мы Друзья» (API-заглушка на Litestar)

Небольшой ASGI-сервер на [Litestar](https://litestar.dev) (Python). Пока это
**заглушка**: данные лежат в `app/data/*.py` (те же объекты, что раньше были
захардкожены во фронте) и отдаются как JSON. Контракты ручек —
в [`../docs/api-contracts.md`](../docs/api-contracts.md).

## Установка и запуск

```bash
cd backend-stub
python3 -m venv .venv
source .venv/bin/activate
pip install -r requirements.txt
litestar --app app.main:app run --port 3001 --reload
```

Сервер поднимется на `http://localhost:3001`. Проверка: `http://localhost:3001/api`.

## Соглашения по данным

- **`id` — целые числа** (`1`, `2`, …), они же попадают в адреса страниц:
  `/classes/1`, `/news/3`. В маршрутах параметр объявлен как `{item_id:int}`,
  поэтому нечисловой id даёт `404`.
- **`color` — HEX-строка** (`"#1a6757"`). Фирменная палитра — в
  `app/data/colors.py`. Светлый и затемнённый оттенки фронт считает сам через
  `color-mix()`, так что достаточно одного цвета.

## Ручки

| Метод | Путь                 | Отдаёт            |
|-------|----------------------|-------------------|
| GET   | `/api/news`          | Список новостей   |
| GET   | `/api/news/{id}`     | Новость целиком   |
| GET   | `/api/classes`       | Список занятий    |
| GET   | `/api/classes/{id}`  | Занятие целиком   |
| GET   | `/api/services`      | Список услуг      |
| GET   | `/api/services/{id}` | Услуга целиком    |
| GET   | `/api/staff`         | Педагоги          |
| GET   | `/api/documents`     | Документы         |
| GET   | `/api/gallery`       | Галерея           |
| GET   | `/media/photos/…`    | Фото центра (файлы) |

## Медиафайлы (фото)

Фотографии лежат в `backend-stub/media/photos/` и раздаются как статика по адресам
вида `/media/photos/090.jpg`.

В ответах API поля `photo`/`photos`/`image` содержат **абсолютные** ссылки —
фронт вставляет их как есть. Ссылка собирается из базового адреса
`MEDIA_BASE_URL` (по умолчанию `http://localhost:3001`):

```
"photo": "http://localhost:3001/media/photos/090.jpg",
"photos": [
  "http://localhost:3001/media/photos/190.jpg",
  "http://localhost:3001/media/photos/300.jpg"
]
```

`photo` — главное фото сущности, `photos` — список остальных фотографий
(галерея). Такие поля есть у занятий, новостей и услуг; у сотрудника — одно
`photo`, оно рисуется в кружке аватара вместо инициалов.

Функция `media_url()` в `app/main.py` — точка, где в проде вместо простого
склеивания адреса будет генерироваться **подписанная ссылка на объект в S3**
(presigned URL). Контракт при этом не меняется: в JSON так же приходит готовая
абсолютная ссылка.

Захардкоженные декоративные фото в шаблонах фронта (hero, «О нас», летние смены)
ссылаются на `/media/…` относительно — их в деве отдаёт прокси Vite, в проде
раздаёт бэкенд/nginx (это статичные картинки, не контент из API).

## Как это связано с фронтом

Фронт (Vite) в дев-режиме проксирует `/api/*` на этот сервер (см.
`frontend/vite.config.ts`), поэтому CORS в разработке не мешает. Данные можно
наполнять здесь — во фронте менять ничего не нужно.

Когда появится настоящая база данных, замените источники данных в `app/main.py`
(импорты из `app/data/…`) на запросы к БД, сохранив формат ответов. Ключи в JSON
намеренно в camelCase, чтобы совпадать с типами фронтенда
(`frontend/src/data/types.ts`).
