# Мы Друзья

Веб-приложение детского центра: публичный сайт и панель управления контентом. Backend на Go, интерфейс на Vue 3 и TypeScript, PostgreSQL для данных и MinIO для файлов.

## Возможности

- Каталог занятий и летних смен, новости, сотрудники, документы, отзывы и галерея.
- Админка: создание и редактирование контента, управление публикацией и загрузка файлов.
- Приём заявок с сайта и работа с ними в админке.
- Авторизация администратора и серверные сессии.
- Обработка изображений: ориентация EXIF, уменьшение до 1920 пикселей и преобразование в JPEG.
- Адаптивный интерфейс, состояния загрузки и ошибок, маршрутизация на клиенте.

## Стек и архитектура

| Слой | Технологии |
| --- | --- |
| Frontend | Vue 3, TypeScript, Vite, Vue Router, PrimeVue |
| Backend | Go 1.26, Chi, pgx |
| Хранение | PostgreSQL 17, MinIO / S3 API |
| Запуск | Docker Compose, многоэтапные Dockerfile, Nginx |
| Проверки | Go tests, vue-tsc, Vite build |

```text
Браузер → Nginx → Vue SPA
             ├── /api/*   → Go API → PostgreSQL
             │                  └─→ MinIO
             └── /media/* → MinIO
```

Go API разделён на HTTP-обработчики, слой доступа к данным, работу с медиа и конфигурацию. SQL-миграции встроены в бинарник и применяются при запуске. Публичные и административные маршруты разделены; административные запросы требуют токен сессии.

## Быстрый старт

Нужны Docker и Docker Compose.

```bash
git clone https://github.com/Fuga12/we-are-friends.git
cd we-are-friends
cp .env.example .env
```

Заполните в локальном `.env` значения `POSTGRES_PASSWORD`, `MINIO_ROOT_PASSWORD` и `ADMIN_PASSWORD`. Для MinIO используйте пароль длиной не менее 8 символов. Не оставляйте эти поля пустыми.

```bash
docker compose up -d --build
docker compose ps
curl http://localhost:8088/api/healthz
```

- Сайт: <http://localhost:8088>
- Админка: <http://localhost:8088/admin>
- Логин: `admin`, пароль — значение `ADMIN_PASSWORD`.
- Порт можно изменить через `WEB_PORT` в `.env`.

На первом запуске создаются схема БД, бакет `media` и начальные записи из SQL-миграций. Остальной контент добавляется через админку. Дамп БД, заявки, загруженные документы и фотографии в репозиторий не входят; на главной используется демонстрационная иллюстрация.

Контейнер сайта слушает только `127.0.0.1`. Для размещения на сервере нужен внешний reverse proxy с HTTPS. Бакет `media` предназначен для общедоступных файлов сайта.

## API

| Маршруты | Назначение |
| --- | --- |
| `GET /api/healthz` | Проверка работы процесса API |
| `GET /api/classes`, `/api/news`, `/api/services` | Контент публичного сайта |
| `GET /api/staff`, `/api/documents`, `/api/gallery` | Сотрудники и материалы |
| `POST /api/leads` | Отправка заявки |
| `POST /api/admin/login` | Получение токена сессии |
| `/api/admin/*` | Управление контентом, файлами и заявками |

Актуальный список маршрутов находится в [router.go](backend-go/internal/httpapi/router.go). Проверка `healthz` подтверждает работу HTTP-процесса, но не заменяет проверку зависимостей.

## Данные и эксплуатация

Рабочая БД и файлы MinIO сохраняются в `data/` (или каталоге из `DATA_DIR`) и исключены из Git. Настройки окружения также исключены; в репозитории остаются только пустые `.env.example`.

```bash
docker compose logs -f api
docker compose down
```

`down` останавливает сервисы; для сохранности контента нужно отдельно резервировать PostgreSQL и MinIO. Учётные данные задаются локально для каждой среды. Исторические фотографии и рабочие данные удалены из публичной истории проекта.

## Ограничения

- Часть текстов и настроек публичного сайта пока хранится во frontend; это приложение конкретного центра, а не универсальная CMS.
- Тесты покрывают конфигурацию, отдельные HTTP-сценарии и обработку медиа. Сквозные браузерные тесты и CI пока не настроены.
- Python-заглушка сохранена как ранний этап разработки; её документация не описывает весь текущий Go API.
